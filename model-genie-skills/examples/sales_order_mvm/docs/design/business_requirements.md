## 1. Project Context

**Customer**: Meridian Manufacturing
**Domain**: Sales Order Management (`sales_order`)
**Layer**: Silver 3NF (hybrid — gold star derived downstream in Mode B)
**Output Model**: `hybrid` · **ETL Type**: `sdp_pipeline` · **SCD**: `type_1`
**Metamodel**: `manufacturing_mvm_v1._metamodel` V3 (mvm scope)

Meridian's sales order domain covers the quote-to-cash commercial operations lifecycle:
quote-to-order workflows, sales order processing, order configuration (CPQ), order promising
(ATP/CTP), credit management, delivery/goods issue, sales contract management, delivery
schedules, OTD tracking, returns (RMA), and multi-channel sales. Sourced from SAP SD,
Salesforce CRM, and a homegrown returns portal.
