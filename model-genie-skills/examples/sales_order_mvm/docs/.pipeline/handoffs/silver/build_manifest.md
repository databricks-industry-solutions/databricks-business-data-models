## Build Notes

- **All entities are Materialized Views** (full recompute each refresh). All sources < 25K rows — MV is always fine.
- **Per-column date formats** verified by probe (Rule C): mixed yyyyMMdd (SAP traditional) and yyyy-MM-dd (SAP custom, Salesforce, Returns) within the same table.
- **'order' entity** backtick-escaped as SQL reserved keyword in CREATE statement and all downstream references.
- **source_system** is a model business column (not _source_system audit column) — the vibe model defines it.
- **Grain guard** uses CASE WHEN ... IS NULL THEN NULL ELSE CONCAT_WS ... END for composite keys (avoids CONCAT_WS NULL-skip trap).
- **FK JOIN dedup** uses ROW_NUMBER() OVER (PARTITION BY join_key) to ensure 1:1 on the lookup side.
- **No build-time testing** (SDP mode — LDP test framework is beta/Editor-only). Confidence from inline EXPECT + event log + downstream validation.
- **Bronze paths hardcoded** as fully-qualified literals (SDP parameterization beta limitation).
